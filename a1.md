## Question 1: Gemi—no, wait a minute \[5 marks\]

### Learning Outcomes

This question is designed to help you learn how to critique algorithms
and proofs, and to give counterexamples against algorithms and proofs.

### Background

Observe that when $g$ is a nonnegative [additive
function](#def-additive), i.e. $g(S) = \sum_{e \in S} w(e)$ for a
nonnegative weight function $w$, then to maximize $g(S)$ subject to
$|S| \leq k$, one can simply pick the elements with $k$ largest weights,
which is equivalent to iteratively picking the element that increases
the objective function the most. As we saw in [Submodular
Maximization](#sec-submodular-max), this greedy approach yields a
[$(1-1/e)$-approximation](#thm-submod-max) for the more general
[problem](#prob-submodular-max) where $g$ is nonnegative submodular.[^1]

Similarly, when $g$ is a nonnegative additive function, to minimize
$g(S)$ subject to $|S| \geq k$, we can simply the elements with $k$
smallest weights. This is equivalent to iteratively picking the element
that increases the objective function the least. Now you start to wonder
whether the same pattern works for minimization as it did for
maximization. Here's a formal description of the minimization problem.

::: {prf:definition label=a1-q1} Submodular Minimization

An instance of the *Submodular Minimization Problem* consists of a
ground set $E$ of $n$ elements, a non-negative monotone submodular
function $g :2^E \rightarrow \mathbb{R}$, and a bound $k$. The goal is
find a subset $S$ with $|S| \geq k$ and minimizes $g(S)$.

:::

Suppose you tell your friend Gemini about your observation. Without
missing a beat, Gemini replies with

::: {note} Gemini

That's an amazingly astute observation, you are absolutely right!

Let's look at the standard greedy algorithm: at each step, you add the
element $e$ that results in the smallest marginal increase, which is
$g(S \cup \{e\}) - g(S)$, where $S$ is the set of elements that you have
picked prior to this step. If we run this greedy algorithm until we pick
exactly $k$ elements, we get a beautiful and mathematically provable
approximation.

Here is the step-by-step logic:

1.  Suppose our greedy algorithm has already picked a set $S_i$ of size
    $i$ (where $i < k$).
2.  Because $g$ is submodular, if we were to add all the remaining
    elements of $S^*$ to our current set $S_i$, the total extra cost
    would be at most $g(S^*)$.
3.  Since there are at least $(k-i)$ elements in $S^* \setminus S_i$,
    there must be at least one element among them whose individual
    marginal cost is at most $\frac{g(S^*)}{k-i}$, i.e. there exists
    $e^* \in S^* \setminus S_i$ such that
    $$g(S_i \cup \{e^*\}) - g(S_i) \leq \frac{g(S^*)}{k-i}.$$
4.  Because the greedy algorithm always picks the element with the
    absolute minimum marginal cost, the $(i+1)$-th element it adds will
    cost no more than $\frac{g(S^*)}{k-i}$.
5.  Thus, if we sum up the total marginal cost of the $k$ elements
    chosen by greedy, we get that the greedy algorithm's cost is at most
    $$\sum_{i=0}^{k-1} \frac{g(S^*)}{k-i} = O(\ln k)g(S^*).$$

:::

As an astute COMP90077 student, you start to critically analyze the
proof instead of accepting it on faith.

## Question 2: Network Redundancy Elimination \[5 marks\]

### Background

Suppose you are managing a communications network. Each network link
incurs a leasing cost daily so you want to discard links while
maintaining connectivity.

### Problem Definition

An instance of *Network Redundancy Elimination* consists of a graph
$G = (V,E)$ with weight function $w$ on edges, the goal is to find a
max-weight subset of edges $R$ such that $E \setminus R$ is connected,
i.e. $G$ is still connected after removing $R$.

### Algorithm Design Task \[4 marks\]

Your task is to reduce the Network Redundancy Elimination Problem to
either the min-weight basis problem or the max-weight basis problem.
There are 4 parts to the task:

**(a)** Describe how to efficiently transform an arbitrary instance $I$
of Network Redundancy Elimination into an instance $\phi(I)$ of either
the min-weight basis or max-weight basis problem.

**(b)** Describe how to efficiently transform an optimal solution for
$\phi(I)$ to an optimal solution for $I$.

**(c)** Prove the correctness of parts a and b.

**(d)** Argue that parts a and b run in polynomial time.

### Reflection Task \[1 mark\]
